**접속** — 학생 `/`(루트) · 관리자 `/?admin=1`(또는 `/admin`). 한 코드베이스가 주소로 갈린다(`src/App.jsx`).
**대상 기기** — 태블릿 가로 + 노트북(1280px↑ 기준, 1024~1279px는 축소). 세로(1023px↓)에선
"가로로 돌려주세요" 안내가 전체를 덮는다(`RotateNotice.jsx`, CSS 미디어 쿼리만·JS 감지 없음).

**공통 색·용어** (모든 색은 CSS 변수, 하드코딩 없음)
- 상승·매수 = **빨강**(`--up`) / 하락·매도 = **파랑**(`--down`) / 보합·정지 = **중립 회색**(`--muted`)
- 강조(진행 버튼·단독 1위) = **골드**(`prime`) / 접속 표시 = **초록** / 위험(리셋·종료) = **빨강**(`danger`)
- 금액은 원 단위 정수. 팝업은 탭/클릭으로 열고 닫는다(hover 전용 없음).

## 학생 화면

`src/App.jsx`의 `Student`가 로그인·데이터 로드·모달 배선을 모두 관리한다. 상태값
(`game`·`positions`·`cash`·`board`·`hints`·`broadcasts` …)은 서버 RPC로만 갱신하고,
실시간 신호가 오면 다시 읽는다(낙관적 업데이트 없음).

### 로그인 (`Login.jsx`)

입장 방식은 **관리자가 게임 설정에서 정한다**(`join_mode`, 공개 조회로 미리 읽어 화면을 분기).

- **코드 방식**(`code`, 기본) — "조별 참가 코드" 입력(예: `TIGER-03`) + **[입장하기]**.
  서버(`login_team`)가 코드를 검증한다. 코드가 곧 신원. 틀리면 에러 문구.
  안내: "참가 코드는 강사 선생님에게 받으세요".
- **자율 입장**(`open`) — **한 화면**(Kahoot식 공용 게임 PIN):
  - **닉네임**("우리 조 이름", 최대 12자) + **입장 PIN**(4자리 숫자) + **[입장하기]**.
    닉네임 2자 미만·PIN 4자리 아니면 버튼 잠금.
  - 입장 PIN은 **강사가 발급해 알려준 공용 게임 PIN**. 처음 닉네임이면 새 조가 생기고, 이미 있는 닉네임이면
    그 조로 재접속한다. 안내: "강사 선생님이 알려준 입장 PIN을 넣으세요…".
  - 에러: 미발급 `아직 입장 PIN이 준비되지 않았어요` · 틀린 PIN `입장 PIN이 틀렸어요` · 시작 후 신규 `대회가 시작돼…`.
  - 같은 기기는 이후 자동 재접속(localStorage 코드, PIN 불필요).
- 우상단 다크/라이트 토글(`ThemeToggle`). 로고 + "CUFIC WTS · 스마트 주식 교실 · 모의투자 시스템".

### 헤더 (`Header.jsx`) — 상단 고정

왼쪽부터 배지, 오른쪽에 계좌 요약·버튼. 로고는 **워드마크 없이 심볼만**.

| 요소 | 표시 / 동작 |
|---|---|
| 팀 배지 | 내 조 이름(없으면 코드) |
| 라운드 배지 | 시작 전 `시작 전 · 대기 중` / 진행 `ROUND N · YYYY년` / 종료 `🏁 최종 · YYYY년` |
| **거래 타이머** (`RoundTimer.jsx` — `TimerPill`) | 시작 후~종료 전. 헤더 필: `거래` 라벨+`M:SS`+**아래 얇은 진행바**(남은 비율). 여유=골드/60초↓=경고(주황)/30초↓=긴급(빨강+점 깜빡임+테두리 발광), 30초 토스트 결합. 대기=`대기`·만료=`마감`. 학생·관리자 헤더 공통 |
| 순위 배지 | `N위 / M조`. 누르면 전체 순위 팝업(`RankingModal`). 순위가 없으면 숨김 |
| 내 힌트 배지 | `내 힌트` + 받은 개수. 누르면 힌트 팝업(`HintModal`) |
| 속보 종(🔔) | 속보가 하나라도 있을 때만. 안 읽은 게 있으면 **깜빡임 + 개수**. 누르면 속보 팝업(`BroadcastModal`) |
| 계좌 요약 | 평가금액 · 주문가능(예수금) · 총 손익(원+%, 빨강 이익/파랑 손실) |
| 테마 토글 · 로그아웃 | 다크/라이트 · 로그아웃 |

> **시황 버튼은 헤더에 없다** — 차트 상단으로 옮겼다(아래 차트 참고). 매매 마감 **30초 전**에는
> 헤더 타이머가 긴급(빨강 깜빡임) 상태로 바뀌는 것과 별개로 "매매 마감 30초 전!" 토스트가 한 번 뜬다(`App.jsx`).

### 왼쪽 — 종목 목록 (`StockList.jsx`)

- 상단: "종목명" 라벨 + **정렬 드롭다운**(기본순 / 이름순 / 가격 높은·낮은순 / 등락률 높은·낮은순).
  기본순 = 등록 순서(`display_order`).
- 종목 행: **종목명만 표시(코드 숨김)**. 보유 중이면 그 아래 `N주 보유`. 오른쪽에 현재가 + 등락률
  (빨강 상승/파랑 하락), **거래정지**(가격 0)면 `거래정지` 태그. 탭하면 가운데 차트가 그 종목으로.
- **상장 예정**(`listed_from_round` 이전 라운드) 종목은 목록에서 **숨김** — 상장 라운드에 등장.
- 하단: **[MY · 내 계좌 / 보유종목]** 버튼(→ `MyModal`).

### 가운데 — 차트 (`Chart.jsx`)

- 상단: 종목명 · 시장(`KOSPI`) · 현재가 · 등락(화살표+폭+%). 거래정지면 `거래정지` 큰 태그.
- **차트 상단 버튼** — **[📈 시황]**(→ `MarketModal`) · **[📊 재무제표]**(→ `FinancialModal`) 순서.
  **시황이 재무제표 왼쪽.** 시황 버튼은 **게임 시작 후에만** 나타난다(`onOpenMarket`이 시작 후에만 전달됨).
- **그리기 도구** — 커서 / 펜(자유 그리기) / 추세선(시작·끝 두 점) / 지우개. 태블릿 터치 대응, 좌표 정규화 저장(`DrawLayer`).
- **봉 주기** 전환(일/주/월/년) — *현재는 같은 1년 구간을 해상도만 바꿔 그린다(알려진 껍데기).*
- 캔들 + 5이동평균선 + 현재가 선. 차트 방향은 실제 등락과 일치(테스트로 고정).

### 오른쪽 — 주문 패널 (`OrderSheet.jsx`)

즉시 체결. 매수·매도가 위에 **고정**돼 화면 높이와 무관하게 항상 보인다(넘치는 보유목록만 아래에서 스크롤).

- **상태 안내 박스**(`거래 대기`) — 이유에 따라 문구가 바뀐다: 종료 시 "대회가 끝났어요…",
  시작 전 "아직 대회가 시작되지 않았어요…", 타이머 밖 "지금은 거래 시간이 아니에요…".
  거래정지 종목이면 별도 `거래정지` 박스("이 종목은 지금 사고팔 수 없어요").
- **매수** — 캡션 "매수 · 최대 N주". 비율 버튼(10% / 25% / 50% / **최대**) · 수량 스테퍼(−/+·직접입력)
  · 예상 매수금액 · **[매수]**(빨강). 누르면 즉시 체결(예수금↓·보유↑), 체결 중엔 "체결 중…".
- **매도** — 캡션 "매도 · 보유 N주". 보유 중이면 평균단가·평가손익(색) 박스. 비율 버튼(10 / 25 / 50 / **전량**)
  · 스테퍼 · 예상 매도금액 · **[매도]**(파랑). 즉시 체결(예수금↑·실현손익 확정).
- **잠금 규칙** — 거래 대기(타이머 밖)·거래정지면 **매수·매도 입력 양쪽을 완전히·동시에 잠근다**(스테퍼·비율 모두 비활성).
  단, **살/팔 수량이 0**일 때(예수금 부족·보유 없음) 비율 버튼을 누르면 잠금 대신 **안내 토스트**
  ("주문가능 금액으로 살 수 있는 수량이 없어요" / "팔 수 있는 보유 주식이 없어요").
- **보유종목**(하단, `QtyStepper.jsx` 아래) — 캡션에 "보유주식 평가 ₩…". 행마다 종목명 · 보유수량 · 금액.
  **상장폐지 종목은 금액 대신 `⚠ 상장폐지`**(전액 손실, delisted 표시). 행을 누르면 그 종목 선택.
  보유 없으면 "아직 가진 종목이 없어요…".
- **첫 안내**(아직 한 번도 거래 안 한 학생에게만) — "매수·매도는 누르는 즉시 체결돼요. …타이머를 시작한
  동안에만 매매… 시간이 끝나면 자동으로 닫혀요." 첫 체결 뒤 사라진다.

## 관리자 화면 (`/?admin=1`)

`src/admin/Admin.jsx`가 인증·데이터 로드·탭 배선을 관리한다. 모든 관리자 RPC는 비밀번호를
받아 서버가 검증(`verify_admin`)한다.

### 로그인 (`Admin.jsx`)

- 로고 + "관리자 · CUFIC WTS · 대회 운영". **관리자 비밀번호** 입력 + **[들어가기]**.
  서버가 대조, 틀리면 토스트. 세션 동안 유지(sessionStorage). 우상단 테마 토글.

### 헤더 (`Admin.jsx`)

- 로고 · **`관리자` 배지** · **게임 상태 배지**(중립색): 시작 전 `시작 전 · 대기 중` / 진행 `ROUND N · YYYY년`
  · **`정산 중` 배지**(라운드 잠금 중일 때) · **거래 타이머 A필**(타이머 진행/대기/마감, 학생과 동일) · 테마 토글 · 로그아웃.

- **[게임 준비]** — 데이터셋 · 종목·가격 · 재무·시황 · 힌트 · 조 관리 (제작 흐름 순서)

### 진행 탭 (`AdminProgress.jsx`) — 대회를 굴리는 곳

게임 루프: **[다음 연도로]로 새 가격·순위 공개 → 순위 확인 → [타이머 시작]으로 거래 개방 →
설정 시간(기본 10분) 뒤 자동 마감 → 다시 [다음 연도로]**. 위에서 아래로 이 순서를 따른다.

1. **대회 준비 시작 카드**(`prep-card`, 시작 전에만) — 순서대로 한 카드에: **①데이터셋 선택**(드롭다운, 바꾸면 확인 모달→세팅·조 유지) →
   **②입장 PIN 발급**(자율 입장이면 큰 골드 PIN + [발급]/[재발급] + "학생들에게 이 번호를 알려주세요" / 코드 방식이면 코드 배부 안내) →
   **③입장 확인**("지금 N개 조 입장함", 실시간) → **④[대회 시작 (ROUND 1 열기)]**. ④는 **자율 입장인데 PIN 미발급이면 경고**(가드).
2. **다음 할 일 배너**(`next-action`, 시작 후) — 상태에 따라 지금 눌러야 할 버튼 하나를 골드로 강조:
   타이머 미개시 → **[타이머 시작]**, 타이머 진행 중 → 없음, 마지막 라운드 → **[대회 종료]**, 그 외 → **[다음 연도로]**.
3. **현재 라운드** 카드(시작 후) — `ROUND N · YYYY년` + 진행률. 큰 버튼 **[다음 연도로 넘어가기]**(골드)/마지막 **[대회 종료]**(빨강).
4. **거래 타이머** 카드(시작 후) — **A안 필**(`거래` M:SS + 진행바, 여유 골드/60초 경고/30초 긴급) + 상태 안내 + **[타이머 시작 (설정 시간)]** + 진행 중 [±1분]. (관리자 헤더에도 같은 A필이 상시 표시.)
   **게임 설정의 타이머 값(기본 10분)으로 시작**, 진행 중엔 **[− 1분]/[+ 1분]**으로 미세 조정. (타이머 판정은 서버 `round_ends_at`.)
5. **속보 · 공통 힌트 (전체 발송)** — 한 줄 입력 + **[전체 발송]**(전 조 종 알림). 발송 목록에서 **[회수]**.
6. **이번 라운드 거래 현황**(시작 후) — `거래한 조 N / M` + 조별 건수 칩.
7. **구분선 "대회 준비"** 아래로 준비 영역:
   - **게임 설정**(시작 전에만) — 요약 + **[설정 편집]** → 라운드 수 · 라운드별 연도 · 최종 정산 연도 ·
     기본 시드머니 · 타이머(분) · **입장 방식([코드]/[자율])**. [설정 저장].
   - **데이터 점검** — **[데이터 점검 실행]**(중립색). 힌트 호재·악재↔실제 등락, 힌트 누락, 가격 공백 등을 검사해
     오류/경고/참고로 리포트(`dataCheck`).
   - **게임 리셋**(펼침 카드, 빨강) — 펼쳐서 **[게임 리셋]** → **`RESET` 입력** 확인 → **[초기화]**.
     전 조 예수금 원금 복귀 + 보유·체결·힌트지급·속보 삭제, 콘텐츠는 유지, R0으로.
- 확인 모달: 라운드 진행 / 대회 종료 / 리셋 / 데이터셋 바꾸기 / 데이터 점검 결과.
- **버튼 색**: 진행 액션 = 골드(`prime`) · 데이터 점검 = 중립(`neutral`) · 리셋·종료 = 빨강(`danger`).

### 리더보드 탭 (`AdminBoard.jsx`)

- 헤더: "조별 순위 · ROUND N · YYYY년" + **[📥 대회 결과 내보내기 (CSV)]** + **[큰 글씨 (프로젝터)]** 토글.
- 순위표 행: 순위 · 조 · **순위 변동(▲▼ / —)** · 평가금액 · 수익률(%+손익). **단독 1위만 골드**(동률 1위는 강조 없음).
- 안내: "순위는 라운드를 넘길 때만 바뀝니다."
- **CSV 내보내기** — 순위(순위·조·평가금액·수익률·손익) + **라운드별 평가금액 스냅샷** + **거래 로그**(라운드·조·종목·구분·체결가·수량·금액·실현손익·시각). 엑셀에서 바로 열리도록 UTF-8 BOM.

### 데이터셋 탭 (`AdminDatasets.jsx`)

게임 데이터 한 벌(종목·가격·재무·시황·힌트·게임설정)의 저장·전환·백업. 제작의 시작이자 끝.

- **지금 편집 중** — 활성 데이터셋 이름(없으면 "(아직 저장 안 함)"). 다른 탭에서 콘텐츠를 고치면
  **`● 저장 안 된 변경` 배지(dirty)** + 안내. **[💾 저장]**(덮어쓰기 확인 모달).
- **새로 저장** — 이름 + 설명 입력 + **[+ 새 데이터셋으로 저장]**.
- **받기** — **[📄 빈 양식 (.xlsx)]**(헤더+예시만) · **[📊 양식 다운로드 (예시 채움 .xlsx)]**(편집 중 데이터셋) · **[📁 데이터 다운로드 (.json)]**.
- **올리기** — **[📊 엑셀 업로드 (.xlsx)]**(시트 파싱·검증 → 오류/경고/참고 리포트 모달 → 이름 정해 **[새 데이터셋으로 생성]**) · **[📁 JSON 가져오기]**.
- 게임 진행 중이면 다른 데이터셋 **[편집] 전환이 잠긴다**(리셋 후 가능) — 경고 표시.
- 데이터셋 목록: 각 행 이름(+`편집 중` 배지)·설명 + **[편집]**(불러오기+게임 리셋, 진행 중·활성이면 잠김) **[엑셀]** **[JSON]** **[삭제]**.
- 확인 모달: 편집 전환(load) / 덮어쓰기(overwrite) / 삭제 / 엑셀 검사 결과.

### 종목·가격 탭 (`AdminStocks.jsx`)

- 헤더: "종목 (N)" + **[+ 종목 추가]**.
- 안내: **가격 0/빈칸 = 거래정지**(매수·매도 차단, 평가액 0). 신규 상장은 이전 연도를 비운다.
  시작 후 수정은 **이미 체결된 거래에 소급 안 됨** 경고.
- 표: 종목(+종목코드 sub) · 소개 · **연도 열(라운드 연도 + 최종 연도)** — 최종 연도 헤더엔 "최종 정산" 라벨,
  값 0/빈칸은 `정지`. 행마다 [수정][삭제].
- **종목 편집기**(`StockEditor` 모달): 종목코드(신규만 입력 가능) · 종목명 · 한 줄 소개 · 업종 ·
  **상장 라운드**(이 라운드부터 노출) · 연도별 가격 그리드. [저장].

### 재무·시황 탭 (`AdminContent.jsx`)

DB의 `financials`·`macro`를 직접 편집. **저장 즉시 학생 화면에 반영**(재배포 없음, `content_changed` 신호).
표는 단일 그리드로 가로 스크롤 없이 한 화면에 들어온다.

- **시황 (거시경제) · 연도별** — 연도마다 6지표(금리·GDP·실업률·환율·물가·유가) 입력 + **[저장]**,
  그 아래 전체 폭 **한 줄 시황 요약** 입력.
- **재무제표 · 종목별** — 종목 드롭다운으로 선택 → 연도마다 **입력 7개**(유동자산·비유동자산·유동부채·비유동부채·매출·영업비용·영업외비용, 전부 억원)
  입력 + **[저장]** / **[비움]**(그 해를 미상장·폐지로 = 행 삭제). 오른쪽에 자본·순익·부채비율·ROE **실시간 계산** 표시(자본잠식 ⚠).

### 힌트 탭 (`AdminHints.jsx`)

- **힌트 풀** — 라운드 탭(R1~RN) + **[+ 힌트 작성]**. 목록은 **S→A→B→C→D 정렬**. 행마다 등급 배지 ·
  헤드라인 · 영향 태그(호재/악재/중립) · 관련 종목(또는 "전체 시장") · `지급 N조` · **`⚠ 등락 불일치` 배지**
  (호재·악재가 관련 종목의 다음 해 실제 등락과 어긋나면). [수정][삭제]. 행을 누르면 아래 지급 대상이 된다.
- **조별 지급** — 고른 힌트 밑에 조 목록(평가금액 낮은 순 = 하위권 먼저): 체크박스 · 순위 · 이름 · 코드 · 평가금액,
  이미 받은 조는 **[지급됨 · 취소]**. **[N개 조에 지급]**. (자동 배분의 보조 수단.)
- **자동 배분 미리보기** — 다음 라운드(R2+) 진입 시 예상 배분표(순위·조·평가금액·받을 힌트). **현재 순위 기준**
  이라 연도를 넘기면 달라질 수 있다는 경고 + 힌트 풀이 없으면 경고. 하위권일수록 좋은 등급·더 많이(꼴찌부터 라운드로빈).
- **힌트 편집기**(`HintEditor` 모달): 라운드 · 등급(S/A/B/C/D) · 영향(호재/악재/중립) · 헤드라인 · 관련 종목(칩). [저장].

> R2부터 [다음 연도로]가 **새 순위(가격 공개 후) 기준으로 자동 배분**한다(하위권 우대). 이 탭 수동 지급은 보조.

### 조 관리 탭 (`AdminTeams.jsx`) — 입장 방식에 따라 다름

- **자율 입장(open)일 때** — 맨 위 **게임 입장 PIN 카드**: 큰 4자리 숫자(골드) + **[PIN 발급]/[PIN 재발급]**
  + "학생에게 알려주세요. 닉네임 + 이 PIN으로 입장합니다." 미발급이면 발급 안내. **[+ 조 추가] 없음**(학생이 직접 입장).
  - 상태줄: "자율 입장 모드 — 닉네임 + 게임 PIN으로 입장" + **[입장 열림]**(R0) / **[입장 마감 · 재접속만]**(시작 후).
  - 학생이 입장하면 **실시간으로 표에 추가**(`teams_changed` 신호). 빈 목록 안내: "아직 입장한 학생이 없어요…".
  - 표 열: **이름**(클릭해 인라인 수정+저장) · 시드 · 예수금 · 평가금액 · 수익률 · 거래 · 힌트 · 접속 · [삭제]. **코드·PIN 열 없음.**
- **코드 방식(code)일 때** — 헤더에 **[+ 조 추가]**(참가 코드 · 조 이름 · 시드머니). 표 맨 앞에 **코드 열**이 있고 나머지는 동일.
- 공통: **시드**는 시작 전엔 클릭해 인라인 편집+저장, 시작 후 읽기전용(잠금 안내). 이름은 두 방식 모두 인라인 수정 가능.
- **접속 표시** — 10분 내 로그인 = `접속 · hh:mm`(초록) / 그 이전 이력 = `이전 접속 hh:mm`(중립) / 없음 = `미접속`.

## 실시간 신호 (참고)

화면들은 `signals` 테이블 + Supabase Realtime으로 서로 갱신된다(`src/gameData.js`의
`subscribeSignals`). 신호를 받으면 각 화면이 필요한 것만 RPC로 다시 읽는다 — 신호 자체엔
데이터를 싣지 않는다.

| 신호 | 언제 | 학생 반응 | 관리자 반응 |
|---|---|---|---|
| `round_advanced` | 연도 넘김 | 새 가격·순위 반영 + 라운드 요약 모달 | 전체 갱신 |
| `timer_started` | 타이머 시작 | 카운트다운 시작 + "거래 시간이 시작됐어요" 토스트 | 갱신 |
| `game_ended` | 대회 종료 | 최종 정산 모달 + 최종 연도 공개 + 토스트 | 갱신 |
| `game_reset` | 게임 리셋 | 초기화 토스트 | 갱신 |
| `hints_changed` | 힌트 지급(자동·수동)·편집 | 내 힌트 갱신, 새로 받았으면 "새로운 힌트가 도착했어요" 토스트 | 갱신 |
| `broadcast` | 속보 발송/회수 | 종 깜빡 + (발송 시) 긴급 속보 팝업 | 갱신 |
| `content_changed` | 재무·시황 저장 | 재무·시황 값 갱신 | 갱신 + dirty 표시 |
| `stocks_changed` | 종목·가격 편집 | 종목·가격 갱신 | 갱신 + dirty 표시 |
| `teams_changed` | 조 추가·삭제·시드 변경 | (해당 없음) | 조 목록 갱신 |
| `sheet_saved` | (레거시) | 무시 | — |

> 클라이언트 카운트다운은 UX용일 뿐, 매매 가능 여부의 최종 판정은 서버(`place_order`가
> `now() < round_ends_at` 검사)다. 마감 뒤 거래는 콘솔로도 못 뚫는다.
