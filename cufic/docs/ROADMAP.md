# 로드맵

지금 어디까지 왔고 뭐가 남았는지. 상태가 바뀌면 갱신한다.
**상세 현황은 [STATUS.md](STATUS.md)**, 규칙은 [GAME_RULES.md](GAME_RULES.md), 운영은 [OPERATIONS.md](OPERATIONS.md).

**현재 위치: 전 과정 동작 + Vercel 배포 완료 (게임 모델 v3 = 즉시 체결 + 라운드 타이머).**
학생·관리자·서버·실시간이 전부 연결돼 돌고, <https://cufic-wts.vercel.app> 에 배포돼 있다.
콘텐츠는 **DB의 데이터셋**으로 관리하며 관리자 화면에서 **엑셀 양식/직접 편집**으로 만든다.
가변 구성(조 수·시드머니·종목 수·라운드 수)으로 전 과정 실측 검증을 마쳤다.

> ⚠ **실제 수업 전 남은 것은 "운영 준비"지 "기능 개발"이 아니다.** 콘텐츠 확정,
> 관리자 비밀번호 강화, 대회 전 초기화 리허설, 실기기 테스트가 남았다. 아래 참고.

---

## ⚠ 실제 수업 전 필수

1. **콘텐츠 확정** — 현재 기본 데이터셋(2020~2024 · 최종 2025 · 18종목)은 **초안**이다. 팀 검토 후
   확정하고, 관리자 [데이터셋] 탭에서 엑셀 양식으로 새 데이터셋을 만든다 → [MANUAL_CONTENT](MANUAL_CONTENT.md).
2. **힌트 자동 배분 순위 해석 컨펌** — 배분 방식은 등급순 × 순위 라운드로빈으로 확정(§4). "직전 정산 순위 = 가격 공개 직후" 해석만 `[잠정]`. 팀 확인 필요([GAME_RULES](GAME_RULES.md)).
3. **관리자 비밀번호 재설정** — 현재 개발 기본값(약함). 강한 값으로 `set_admin_secret()` + `.env`/Vercel 동시 변경.
4. **대회 전 초기화 리허설** — [게임 리셋]으로 테스트/플레이테스트 흔적 제거. **개발 DB가 곧 대회 DB다.**
5. **실기기 테스트** — 실제 태블릿 그리기·터치·회전(지금까지 헤드리스 + 로컬 위주).
6. **당일 회선 점검** — 교육장 와이파이에서 Vercel·Supabase 접속, 전날 Supabase 활성 상태 확인([OPERATIONS](OPERATIONS.md)).

---

## 대기 (일정 미정)

- **[잠정] 결정 확인** — 지시서 없이 직접 설계한 부분(실시간 신호 방식, 힌트 매핑, 자동 배분 UI, 자율 입장 PIN
  방식). 팀 결정 도착 시 대조.
- **순위 상시 노출 유지 여부** — 팀 결정 대기(현재 팝업 + 리더보드 탭 + 라운드 요약 전체 순위표).
- **봉 주기 실데이터화** — 일/주/월/년이 전부 같은 구간(알려진 껍데기, `chart.js`).
- **종목명 표기 방식** — 실명/가명 미정(현재 학생 화면은 종목코드 숨김).
- **파일 정리** — `index.css` 분리(리팩터).

## 알려진 한계

1. **관리자 계정 분리가 없다** — 비밀번호를 입력하면 서버(`verify_admin`)가 대조한다. `VITE_ADMIN_PASSWORD`는
   src에서 참조하지 않아 **번들에 안 들어간다.** 교육용 수준이며, 진짜 계정 분리는 Supabase Auth + service role 필요.
2. **참가 코드/PIN을 아는 사람은 그 조로 입장할 수 있다** — 코드/자율 입장 인증의 본질.
3. **힌트 Realtime 직접 구독 불가** — RLS 대신 RPC로 격리해서. signals 우회(신호→재조회)라 약간 지연.
4. **개발 DB = 대회 DB** — 분리된 개발 프로젝트가 없다. 검증은 테스트 조 코드로만.
