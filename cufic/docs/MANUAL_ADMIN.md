# 강사용 매뉴얼 (MANUAL_ADMIN) — 관리자 화면 조작법

> **이 문서만 보면 대회 준비부터 진행·종료까지 관리자 화면을 조작할 수 있게** 실제 버튼 기준으로 정리했다.
> 코드가 곧 진실이며(2026-08 기준 화면), 화면·버튼이 바뀌면 이 문서를 함께 고친다.
>
> - **역할 구분**: 이 문서는 **화면 조작법**(탭·버튼·동작). 당일 진행 순서·인프라 점검(Supabase 깨우기,
>   비밀번호 교체 절차 등)은 **[OPERATIONS.md](OPERATIONS.md)** 를 함께 본다.
> - 게임 규칙(라운드·힌트 배분 원리): **[GAME_RULES.md](GAME_RULES.md)** · 데이터 만들기: **[MANUAL_CONTENT.md](MANUAL_CONTENT.md)**

**한 줄 요약**: **[데이터셋]에서 게임 데이터 한 벌을 불러오고 → [조 관리]에서 조를 만들고 →
[진행]에서 [대회 시작] → [타이머 시작] → (매매) → [다음 연도로] 를 라운드마다 반복하다가 → [대회 종료].**

라운드 루프(외우면 편하다):

```
[다음 연도로]  →  순위 확인(리더보드)  →  [타이머 시작]  →  학생 매매  →  자동 마감  ↺
 (가격 공개·순위 갱신·힌트 배분)              (설정 시간·기본 10분)
```

## 1. 들어가기 (진입)

`[스크린샷: 관리자 로그인 화면]`

1. 학생 화면 주소 뒤에 **`?admin=1`** 을 붙여 연다 — 예: `배포주소/?admin=1`. (`배포주소/admin` 경로도 같다.)
2. **관리자 비밀번호**를 입력하고 [들어가기]. 비밀번호는 브라우저 **탭이 열려 있는 동안만 기억**되므로
   새 탭·새 창에서는 다시 입력한다. 우측 상단 [로그아웃]으로 즉시 잠근다.
3. 비밀번호가 틀리거나 아직 서버에 설정되지 않았으면 모든 기능이 `unauthorized`로 잠긴다(→ OPERATIONS §A-3, D).

**상단 표시줄**로 현재 상태를 늘 확인할 수 있다.

- `관리자` 배지 — 관리자 화면임을 표시.
- `시작 전 · 대기 중` **또는** `ROUND N · YYYY년` — 지금 몇 라운드인지.
- `정산 중` — 대회 종료 정산이 진행되는 순간에만 잠깐 뜬다.

**왼쪽 탭은 두 묶음**이고, 각 탭 위엔 한 줄 도움말이 있다.

| 묶음 | 탭 | 하는 일 |
|---|---|---|
| **대회 운영** | 진행 | 라운드 넘기기·타이머·속보·게임 설정·리셋 |
|  | 리더보드 | 조별 순위(프로젝터용 큰 글씨)·결과 CSV 내보내기 |
| **게임 준비** | 데이터셋 | 게임 데이터 한 벌의 저장·전환·백업(엑셀·JSON) |
|  | 종목·가격 | 종목과 연도별 가격 |
|  | 재무·시황 | 종목별 재무제표·연도별 거시지표 |
|  | 힌트 | 라운드별 힌트 작성·자동배분 미리보기·수동 지급 |
|  | 조 관리 | 참가 조·시드·접속 / 자율 입장이면 게임 PIN 발급·이름 수정 |

## 2. 꼭 알아야 할 개념 — '라이브'와 '데이터셋'

**이 구분을 모르면 애써 만든 데이터가 사라진다.**

- **라이브(live)** = 지금 학생 화면에 보이는 콘텐츠 한 벌(종목·가격·재무·시황·힌트·게임설정).
  **[종목·가격]·[재무·시황]·[힌트] 탭에서 고치면 재배포 없이 학생 화면에 즉시 반영**된다.
- **데이터셋(dataset)** = 라이브 콘텐츠를 **통째로 저장해 둔 백업/시나리오**. 여러 벌을 만들어 두고 바꿔 쓸 수 있다.
  라이브를 고쳐도 **데이터셋에는 자동으로 담기지 않는다** — [데이터셋] 탭에서 **[💾 저장]**을 눌러야 담긴다.

| 동작 | 결과 |
|---|---|
| [종목·가격]/[재무·시황]/[힌트]에서 편집 | **라이브(학생 화면) 즉시 변경**. 데이터셋엔 아직 안 담김 → [데이터셋] 탭에 **"● 저장 안 된 변경"** 배지 |
| [데이터셋] → **[💾 저장]** | 지금 라이브를 **편집 중인 데이터셋에 덮어쓰기**(원래 내용 교체) |
| [데이터셋] → **[+ 새 데이터셋으로 저장]** | 지금 라이브를 **새 데이터셋으로** 저장(기존 것 안 건드림) |
| 데이터셋 **[편집]** / 진행 탭 드롭다운 전환 | 그 데이터셋을 **라이브로 불러오고 게임 리셋**(조는 유지). **저장 안 한 편집은 사라짐** |

> ⚠ **저장 안 하고 다른 데이터셋으로 [편집] 전환하면 그 편집은 사라진다.** 그래서 "● 저장 안 된 변경" 배지로 경고한다.
> 콘텐츠를 고쳤으면 전환 전에 [데이터셋] → [💾 저장]부터.

## 3. 대회 준비 (시작 전에 다 끝내둘 것)

> 준비 작업의 상당수는 **게임이 "시작 전(ROUND 0)"일 때만** 가능하다(시드 변경, 게임 설정, 데이터셋 전환).
> 이미 진행 중이면 먼저 [진행] 탭에서 **게임 리셋**부터.

### 3-1. 쓸 데이터를 라이브로 올리기 — 데이터셋 고르기

`[스크린샷: 진행 탭 '대회 준비' 시작 카드 — ①데이터셋 ②PIN ③입장확인 ④대회 시작]`

- **간편한 길**: [진행] 탭 맨 위 **"대회 준비"** 시작 카드가 시작 절차를 순서대로 안내한다 —
  **①데이터셋 선택** 드롭다운에서 쓸 데이터셋을 고르면 확인 모달 후 라이브가 세팅되고 R0로 리셋(조 유지) →
  **②입장 PIN 발급** → **③입장 확인**(입장한 조 수) → **④[대회 시작]**.
- **또는** [데이터셋] 탭에서 원하는 데이터셋 행의 **[편집]** → 확인 → 같은 동작.
- 이미 원하는 데이터가 라이브에 올라 있으면 이 단계는 건너뛴다.
- 저장된 데이터셋이 하나도 없으면 드롭다운이 비어 있다 → [데이터셋] 탭에서 먼저 만든다(§6 데이터셋 참고).

### 3-2. 게임 설정 확인·변경 — [진행] 탭 "게임 설정 (시작 전에만)"

`[스크린샷: 진행 탭 게임 설정 편집]`

[설정 편집]을 누르면 다음을 바꾼다. 다 정하면 [설정 저장].

- **라운드 수**(1~20) · **라운드별 연도**(R1=2020 …) · **최종 정산 연도**(마지막에 공개할 해)
- **기본 시드머니**(조를 새로 만들 때 기본값) · **타이머(분)**
- **입장 방식** — 아래 3-3.

### 3-3. 입장 방식 정하기 — 코드 vs 자율

- **코드**(기본): 강사가 [조 관리]에서 조와 **참가 코드**를 만들어 나눠주고, 학생은 코드로 입장한다.
- **자율(open)**: 학생이 **닉네임 + 공용 게임 PIN**으로 직접 입장한다(Kahoot식). 강사가 **게임 입장 PIN 하나**를 발급해
  전원에게 알려주고, 학생은 닉네임을 정해 그 PIN으로 들어온다. 조가 실시간으로 [조 관리] 표에 나타난다. **새 입장은 시작 전에만.**
  - **게임 입장 PIN 발급** — [진행] 탭 맨 위 **"대회 준비" 시작 카드 ②단계**(또는 [조 관리] 탭 PIN 카드)에서 **[PIN 발급]**(또는 [재발급]).
    나온 4자리를 학생에게 전달. 발급 전에는 학생이 입장할 수 없고, 자율 입장인데 PIN을 안 만들고 [대회 시작]을 누르면 경고가 뜬다.

### 3-4. 조 만들기 — [조 관리] 탭

`[스크린샷: 조 관리 탭 표]`

- **코드 방식**: **[+ 조 추가]** → **참가 코드**(예: `TIGER-03`)·**조 이름**·**시드머니**(비우면 기본값) → [추가].
  표에 코드가 그대로 보인다 — 이 코드를 각 조에 배부한다.
- **자율 방식**: 강사가 미리 만들 필요 없다. 맨 위 카드에서 **게임 입장 PIN을 발급**해 학생에게 알려주면, 학생이 닉네임으로
  들어오는 대로 표에 자동으로 뜬다. **코드·PIN 열은 없다**(공용 PIN 하나라 표에 안 나온다). 표의 **이름을 눌러 인라인 수정** 가능(부적절 닉네임 교정).
- **시드머니는 시작 전에만** 표의 시드 숫자를 눌러 바꾼다(진행 중이면 잠김).
- **접속 열**로 각 조가 로그인했는지 본다 — **최근 10분 이내면 초록 "접속 · 시각"**, 오래됐으면 "이전 접속 시각", 없으면 "미접속".

### 3-5. 데이터 점검 — [진행] 탭 "데이터 점검"

- **[데이터 점검 실행]** → 힌트 호재/악재 ↔ 다음 해 실제 등락, 힌트 누락, 가격 공백 등을 검사한다.
- 결과 모달에서 **오류(빨강)는 0이어야** 안전하다(경고·참고는 판단해서 무시 가능).

### 3-6. 리허설 흔적 지우기 — 리셋 + 테스트 조 삭제

- **[진행] 탭 → "게임 리셋 (펼쳐서 실행)"** 펼치기 → [게임 리셋] → **RESET** 입력 → [초기화].
  모든 조의 거래·보유·힌트 지급이 지워지고 R0로 돌아간다(**종목·힌트 등 콘텐츠는 남는다**).
- **[조 관리]** 에서 `TEST-01`·`TIGER-03` 같은 검증용 조를 **[삭제]**. 안 지우면 학생 리더보드에 테스트 조가 보인다.

### 3-7. 관리자 비밀번호 강화

- 실전 전 강한 값으로 바꾼다. **값은 이 문서에 적지 않는다.** 교체 절차는 [OPERATIONS.md](OPERATIONS.md) §A-3.

## 4. 당일 진행 — [진행] 탭에서 라운드 루프 돌리기

`[스크린샷: 진행 탭 '다음 할 일' + 현재 라운드 + 거래 타이머]`

> 💡 [진행] 탭 맨 위 **"다음 할 일"** 카드가 **지금 눌러야 할 버튼 하나**를 크게 강조한다.
> 이것만 따라 눌러도 진행된다: 대회 시작 → 타이머 시작 → 다음 연도로 → … → 대회 종료.
> (거래가 진행 중일 땐 "다음 할 일" 대신 **거래 타이머** 카드가 주인공이 된다.)

### 순서

1. **입장 확인** — 학생이 코드(또는 닉네임)로 로그인. [조 관리]·[리더보드]의 접속 표시로 전원 확인.
2. **대회 시작** — **[대회 시작 (ROUND 1 열기)]** → 확인 모달 → [진행]. R1(첫 연도) 가격이 열린다.
3. **거래 열기** — **거래 타이머** 카드에서 **[타이머 시작 (설정 시간)]**. 학생 매매 시작, **설정한 시간** 뒤 자동 마감.
   - **[+ 1분] / [− 1분]** — 진행 중에만 뜬다. 시간을 늘리거나 줄인다.
   - 다시 열려면 **[타이머 다시 시작 (설정 시간)]**.
   - **타이머 길이 = 게임 설정의 '타이머(분)' 값**(기본 10분). 버튼 라벨에 그 분수가 표시되고, 진행바 기준도 이 값이다.
     미세 조정은 시작 후 **±1분** 버튼으로 한다.
4. **다음 연도로** — 매매가 끝나면 **[다음 연도로 넘어가기 (순위 갱신)]** → 확인 → 다음 해 가격이 공개되고
   보유가 재평가돼 **순위가 갱신**되며, **(R2부터) 새 순위 기준으로 힌트가 자동 배분**된다(하위권 우대).
   - 아직 타이머가 남아 있는데 넘기면 확인 모달이 "거래가 바로 닫힙니다"라고 경고한다.
   - 힌트 등급이 부족했으면 "인접 등급으로 대체됐어요" 경고 토스트가 뜬다 — 필요하면 [힌트] 탭에서 보정.
5. **순위 확인** — [리더보드] 탭 **큰 글씨(프로젝터)** 모드로 학생에게 순위 변동을 보여준다.
6. **3~5 반복** — 마지막 라운드까지.
7. **대회 종료** — 마지막 라운드에선 버튼이 **[대회 종료]** 로 바뀐다 → 확인 → **최종 연도 가격으로 최종 정산**.
   전 학생 화면에 종료 결과 모달(최종 순위·수익률)이 뜬다. (자세히는 §5)

> **핵심 순서**: 연도 넘기기(가격·순위·힌트) → 순위 확인 → 타이머 시작(거래).
> **타이머를 안 열면 학생은 매매하지 못한다**(전 종목이 "거래정지"처럼 보인다).
> [대회 시작]·[다음 연도로]·[대회 종료]는 **확인 모달**을 거치며 **되돌릴 수 없다.**

### 라운드 중에 할 수 있는 것

- **속보 · 공통 힌트 (전체 발송)** — 입력칸에 한 줄(최대 120자) → **[전체 발송]**. 전 조 화면에 종 알림으로 즉시 뜬다.
  보낸 목록의 **[회수]** 로 취소한다. (조별 등급 힌트와는 별개다.) `[스크린샷: 진행 탭 속보]`
- **거래 현황 보기** — "이번 라운드 거래 현황"에 **"거래한 조 N / M"** 와 조별 매매 건수 칩이 보인다.
- **수동 힌트 지급** — [힌트] 탭에서 자동 배분을 보조로 조정(§6 힌트).

## 5. 종료·결과 내보내기 — [리더보드] 탭

`[스크린샷: 리더보드 큰 글씨 모드]`

- **[대회 종료]** 를 누르면 최종 정산이 끝나고 전 학생 화면에 종료 모달이 자동으로 뜬다.
- **순위 표** — 라운드가 넘어갈 때만 바뀐다. **단독 1위만 골드**로 강조(공동 1위면 아무도 강조 안 함).
  각 조에 직전 대비 **순위 변동(▲/▼/—)** 이 표시된다.
- **[큰 글씨 (프로젝터)]** 토글 — 시상·발표용. 다시 누르면 [보통 글씨].
- **[📥 대회 결과 내보내기 (CSV)]** — 아래 3부분을 한 파일(`대회결과.csv`, 엑셀에서 바로 열림)로 받는다.
  1. **[순위]** — 순위·조·평가금액·수익률(%)·손익
  2. **[라운드별 평가금액(스냅샷)]** — 조별로 R1…R5·최종 열
  3. **[거래 로그]** — 라운드·조·종목·구분(매수/매도)·체결가·수량·체결금액·실현손익·시각

## 6. 탭별 조작 레퍼런스

앞 절과 겹치는 [진행]·[리더보드]는 요점만, 준비용 탭은 버튼별로 정리한다.

### 진행

- **이번 게임 데이터셋**(시작 전만) — 드롭다운으로 라이브에 올릴 데이터셋 선택(§3-1).
- **다음 할 일** — 지금 누를 버튼 하나를 강조.
- **현재 라운드** — [대회 시작]/[다음 연도로]/[대회 종료] 큰 버튼(확인 모달).
- **거래 타이머**(시작 후) — [타이머 시작 (설정 시간)] / [다시 시작] / [±1분]. mm:ss 카운트다운.
- **속보 · 공통 힌트** — 전체 발송 / 회수.
- **이번 라운드 거래 현황**(시작 후) — 거래한 조 수·건수.
- **게임 설정**(시작 전만) — 라운드·연도·최종연도·시드·타이머·입장방식.
- **데이터 점검** — 정합성 검사 모달.
- **게임 리셋 (펼쳐서 실행)** — RESET 입력 → 거래·보유·힌트 초기화(콘텐츠·조 유지).

### 리더보드

- 순위 표(단독 1위 골드) · [큰 글씨(프로젝터)] 토글 · [📥 대회 결과 내보내기 (CSV)] (§5).

### 데이터셋

`[스크린샷: 데이터셋 탭]`

- **지금 편집 중** — 라이브가 담긴(또는 담길) 데이터셋 이름. 콘텐츠를 고쳐 저장 안 했으면 **"● 저장 안 된 변경"** 배지.
  - **[💾 저장]** — 지금 라이브를 이 데이터셋에 **덮어쓰기**(확인 모달, 원래 내용 교체).
- **[+ 새 데이터셋으로 저장]** — 이름(+설명) 넣고 지금 라이브를 **새 데이터셋**으로 저장.
- **받기** — **[📄 빈 양식 (.xlsx)]**(처음부터 만들 때) · **[📊 양식 다운로드 (예시 채움 .xlsx)]**(지금 데이터를 엑셀로) ·
  **[📁 데이터 다운로드 (.json)]**(백업용).
- **올리기** — **[📊 엑셀 업로드 (.xlsx)]** → **검사 리포트 모달**(오류가 있으면 차단, 경고·참고는 통과) →
  이름 정하고 **[새 데이터셋으로 생성]**. **[📁 JSON 가져오기]** — 내보낸 JSON을 새 데이터셋으로.
- **데이터셋 목록** — 각 행: **[편집]**(라이브로 불러오기+게임 리셋, **진행 중엔 잠김**) · **[엑셀]** · **[JSON]** · **[삭제]**.
  현재 라이브인 행엔 **"편집 중"** 배지.

> ⚠ 엑셀 업로드는 **기존 데이터셋 덮어쓰기가 아니라 항상 새 데이터셋 생성**이다. 실수로 덮어써질 걱정은 없다.

### 종목·가격

`[스크린샷: 종목·가격 표]`

- **[+ 종목 추가]** / 행별 **[수정]·[삭제]**.
- 편집 항목: 종목코드(수정 시 잠김)·종목명·한 줄 소개·업종·**상장 라운드**(이 라운드부터 학생에게 노출)·**연도별 가격**.
- **가격을 0으로 두거나 비우면 거래정지**(매수·매도 차단, 평가액 0). **신규 상장**은 그 이전 연도를 비워둔다.
- 표에서 가격이 0인 칸은 **"정지"** 로, 최종 정산 연도 열은 **"최종 정산"** 으로 표시된다.
- ⚠ **대회 시작 후 가격을 고쳐도 이미 체결된 거래엔 소급되지 않는다**(앞으로의 평가·체결에만 적용).

### 재무·시황

`[스크린샷: 재무·시황 편집]`

- 여기서 고치면 **재배포 없이 학생 화면에 즉시 반영**된다(데이터셋에 담으려면 [데이터셋] → [💾 저장]).
- **시황(거시경제) · 연도별** — 연도별로 기준금리·GDP성장률·실업률·환율·물가상승률·국제유가 입력 + **한 줄 시황** →
  행마다 **[저장]**.
- **재무제표 · 종목별** — 위 **종목 드롭다운**으로 종목을 고르고, 연도별로 **입력 7개**(유동자산·비유동자산·유동부채·비유동부채·매출·영업비용·영업외비용) 입력.
  - 전부 **억원**. 자본·순익·부채비율·ROE는 오른쪽에 **자동 계산** 표시(입력 X, 자본잠식이면 ⚠).
  - 행별 **[저장]** / **[비움]**(그 해 재무를 지워 미상장·폐지로 처리).

### 힌트

`[스크린샷: 힌트 탭 — 풀·지급·미리보기]`

- **힌트 풀** — 상단 **R1…R5 탭**으로 라운드 선택, **[+ 힌트 작성]**. 각 힌트는 **등급(S·A·B·C·D)**,
  **영향(호재/악재/중립)**, 헤드라인, **관련 종목**(없으면 전체 시장)을 가진다. 행별 [수정]·[삭제].
  - 호재/악재 태그가 관련 종목의 다음 해 실제 등락과 어긋나면 **"⚠ 등락 불일치"** 가 표시된다 — 바로잡는다.
- **자동 배분 미리보기** — **R{다음 라운드} 진입 시** 순위대로 어떤 힌트가 나갈지 **현재 순위 기준 예상**.
  꼴찌부터 라운드로빈으로 좋은 등급을 더 많이 준다. 실제 배분은 [다음 연도로]가 **새 가격 공개 후 순위**로 하므로 달라질 수 있다.
  - **R1은 지급 없음.** 다음 라운드 힌트 풀이 비어 있으면 경고가 뜬다 → 먼저 힌트 작성.
- **조별 지급(수동 보조)** — 왼쪽에서 힌트 하나를 고르고, 조 목록에서 줄 조를 체크 → **[N개 조에 지급]**.
  이미 지급된 조는 **[지급됨 · 취소]** 로 회수한다. (평소엔 자동 배분으로 충분하고, 이건 보정용이다.)

### 조 관리

- **자율 입장(open)**: 맨 위 **게임 입장 PIN 카드** — **[PIN 발급]/[재발급]** 후 학생에게 전달. [+ 조 추가] 없음(학생이 직접 입장).
  표 열: **이름**(클릭해 수정)·시드·예수금·평가금액·수익률·거래·힌트·접속·[삭제]. 코드·PIN 열 없음.
- **코드(code)**: **[+ 조 추가]**(참가 코드·조 이름·시드머니), 표 맨 앞에 **코드 열**.
- 공통: 행별 **[삭제]**(보유·체결·힌트 함께 삭제), **시드**는 시작 전만 클릭해 변경, **접속**(10분 이내 초록).

## 7. 자주 막히는 것 (트러블슈팅)

| 증상 | 원인 | 대처 |
|---|---|---|
| 학생이 "매매가 안 돼요" | 타이머를 안 열었음 | [진행] → [타이머 시작 (설정 시간)] |
| 전 종목이 "거래정지" | 아직 R0(시작 전)이거나 그 라운드 가격이 0 | [대회 시작]/[다음 연도로]로 라운드를 열기 |
| 데이터셋 [편집] 전환이 잠김 | 게임 진행 중 | [진행] → 게임 리셋 후 [편집] |
| 고친 콘텐츠가 데이터셋에 없음 | [💾 저장]을 안 눌렀음 | [데이터셋] → [💾 저장]. 전환 전에 먼저 저장 |
| "● 저장 안 된 변경" 배지가 떠 있음 | 라이브를 고쳤는데 데이터셋 미저장 | 저장하거나, 버릴 거면 무시하고 전환(사라짐) |
| 순위가 안 바뀜 | 라운드 중엔 가격이 안 변함(정상) | [다음 연도로] 해야 순위가 움직임 |
| 힌트가 안 나감 | R1이거나 그 라운드 힌트가 없음 | R2부터 자동. [데이터 점검]·[힌트] 미리보기로 누락 확인 |
| "⚠ 등급 힌트 부족" 경고 | 그 등급 힌트가 풀에 없어 인접 등급으로 대체 | [힌트] 탭에서 부족 등급 힌트 추가 |
| 시드머니를 못 바꿈 | 대회가 시작됨(R0 아님) | 게임 리셋 후 변경(또는 시작 전에 설정) |
| 학생 화면이 폰에서 안 열림 | 세로 화면 미지원 | 노트북/태블릿 **가로**로 |
| 관리자 기능이 "unauthorized" | 비밀번호 불일치/미설정 | 비밀번호 확인(OPERATIONS §A-3, D) |
| 모든 화면이 "fetch failed" | Supabase 프로젝트 일시정지 가능성 | OPERATIONS §D(대시보드에서 Resume) |

> ⚠ **[다음 연도로]와 [대회 종료]는 되돌릴 수 없다.** 넘기기 전에 순위·거래가 끝났는지 확인한다.
