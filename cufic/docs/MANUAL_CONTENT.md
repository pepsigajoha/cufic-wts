# 콘텐츠 제작 매뉴얼 (MANUAL_CONTENT)

> **대상: 개발을 몰라도 되는 콘텐츠 제작자(교보재팀).** 이 문서만 보면 게임 한 판 데이터
> (종목·가격·재무·힌트·시황·게임설정)를 **엑셀** 또는 **관리자 화면**으로 처음부터 끝까지 만들 수 있다.
> 실제 화면·버튼·시트 이름 기준이고, 매 단계에 예시가 있다.
> (갱신: 2026-08-20 · 엑셀 v4 정본 양식 + 화면 편집 두 갈래 기준)
>
> **형식의 세부 규칙·정합성 안전장치·(개발자용) 파일 파이프라인**은 [DATA_GUIDE.md](DATA_GUIDE.md)에 있다.
> 이 문서는 **"어떻게 만드나"**에 집중하고, 겹치는 형식 상세는 그쪽을 가리킨다.

## 0. 시작 전에 (공통)

**관리자 화면 접속**: `배포주소/?admin=1` → 관리자 비밀번호 입력.

왼쪽 탭은 두 묶음이다. 콘텐츠 제작은 **[게임 준비]** 쪽에서 한다(제작 흐름 순서로 배열돼 있다).

| 묶음 | 탭 | 하는 일 |
|---|---|---|
| **대회 운영** | 진행 · 리더보드 | 대회 당일 진행(연도 넘기기·타이머). **여기서 게임 설정·데이터 점검·리셋도 한다** |
| **게임 준비** | 데이터셋 · 종목·가격 · 재무·시황 · 힌트 · 조 관리 | 콘텐츠 제작·저장 |

> 💡 **작업 전에 반드시 게임이 "시작 전(ROUND 0)" 상태여야 한다.** 그래야 게임 설정을 바꾸고 다른
> 데이터셋으로 전환할 수 있다. 진행 중이면 [진행] 탭 맨 아래 **[게임 리셋 (펼쳐서 실행)]** → `RESET`
> 입력으로 되돌린다. (리셋은 **콘텐츠는 안 지우고** 진행 상태·거래만 지운다.)

### 한 게임은 무엇으로 이뤄지나

| 요소 | 엑셀 시트 | 관리자 탭 | 학생 화면 어디에 |
|---|---|---|---|
| **게임 설정** (라운드 수·연도·최종연도·시드·타이머) | 게임설정 | 진행 → 게임 설정 | 헤더의 ROUND/연도, 거래 타이머 |
| **종목 + 연도별 가격** | 종목 | 종목·가격 | 왼쪽 종목 목록·가운데 차트·현재가 |
| **종목 한 줄 소개** | 종목(한 줄 소개 열) | 종목·가격(편집기) | [재무제표] 팝업 맨 위 |
| **재무제표** (연도×입력 7개) | 재무제표 | 재무·시황 | [재무제표] 버튼 → 재무상태표+손익계산서 팝업 |
| **시황(거시지표)** (연도별 6지표) | 시황 | 재무·시황 | [시황] 버튼 → 팝업 |
| **힌트** (라운드·등급·문구·방향·관련종목) | 힌트 | 힌트 | [내 힌트] 버튼 → 팝업(조마다 다름) |
| **조 / 참가 코드** | (없음) | 조 관리 | (대회 때 생성 — 콘텐츠 아님) |

### 만드는 순서 (이 순서를 지킨다)

**① 게임설정 → ② 종목·가격 → ③ 재무제표 → ⑤ 시황 → ④ 힌트**

- **게임설정을 먼저**: 여기서 정한 연도들이 이후 모든 시트·화면의 "연도 칸"을 만든다.
- **가격이 게임의 뼈대**: 소개·재무·힌트·시황이 전부 "이 종목이 이 해에 오른다/내린다"는 가격 스토리에서
  파생된다. **힌트는 맨 마지막** — 가격이 확정된 뒤라야 방향(호재/악재)을 맞출 수 있다.

### 두 갈래 — 엑셀 vs 화면

| | **엑셀로 만들기** (§1, 추천) | **화면으로 만들기** (§2) |
|---|---|---|
| 언제 | 한 판을 **통째로** 새로 만들 때, 익숙한 엑셀에서 대량 입력 | 이미 있는 데이터셋을 **세밀 수정**, 몇 칸만 고칠 때 |
| 반영 | 업로드 → 검사 → **새 데이터셋**으로 생성 (기존 안 건드림) | **즉시 라이브** 반영(학생 화면 바로 바뀜) → [데이터셋]에 저장 |
| 장점 | 오프라인 작업·검토·백업 쉬움, 업로드 시 **전체 검사 리포트** | 방향 불일치 배지·자동배분 미리보기 등 즉석 피드백 |

두 갈래는 **섞어 써도 된다.** 보통 엑셀로 뼈대를 만들어 올린 뒤, 화면에서 힌트 문구 등을 다듬는다.

## 1. 엑셀로 만들기 (추천 · 한 판 통째로)

엑셀만 알면 게임 한 판을 통째로 만들 수 있다. **정본 양식은 `docs/CUFIC_WTS_데이터셋_제작양식.xlsx`**
(기본 데이터셋 "2025"가 예시로 채워져 있고, **필수=노랑·선택=파랑**으로 색칠돼 있다). 시트는 **6개** — 읽어주세요(안내) / 게임설정 / 종목 /
재무제표(**입력 7개**) / 힌트 / 시황. 헤더에 **"(선택)"**이 붙은 열은 비워도 된다.
> ⚠ 옛 **v3**는 `docs/archive/`에 대조용으로만 보관한다 — 재무 시트가 옛 5지표라 **업로드하면 재무가 깨진다.** 반드시 v4(또는 화면 [받기])를 쓸 것.

### 1-1. 양식 받기 — [데이터셋] 탭 → "받기"

[데이터셋] 탭 상단 **받기** 줄에 버튼 세 개가 있다.

| 버튼 | 받는 것 | 언제 |
|---|---|---|
| **[📄 빈 양식 (.xlsx)]** | 헤더 + 형식을 보여주는 **예시 2줄만** | 완전히 처음부터 만들 때 |
| **[📊 양식 다운로드 (예시 채움 .xlsx)]** | **지금 편집 중**인 데이터셋 전체 | 기존 게임을 고쳐서 새로 만들 때 (편집 중 데이터셋이 있어야 눌림) |
| **[📁 데이터 다운로드 (.json)]** | 편집 중 데이터셋의 백업 파일 | 팀 공유·인수인계용 (엑셀 아님) |

> 특정 데이터셋만 받으려면 아래 **목록 각 행의 [엑셀] / [JSON]** 버튼을 쓴다.
> 저장소의 `docs/CUFIC_WTS_데이터셋_제작양식.xlsx`(정본)를 팀에서 공유받아 써도 된다(화면 [받기]와 같은 구조).

### 1-2. 시트별 채우기 규칙

공통: **행은 자유롭게 추가/삭제**해도 된다(종목·힌트 개수 무제한). 지표 열은 **이름(키워드)으로 찾으므로
열 순서를 바꾸거나 열을 추가해도 된다** — 모르는 열은 "무시됨"으로 넘어간다.

#### 「읽어주세요」 (안내 — 채우지 않음)
양식 사용법 안내만 있는 시트. 읽고 지나간다.

#### 「게임설정」 — 항목 / 값
A열(항목 이름)은 **그대로 두고 B열(값)만** 고친다.

| 항목 | 값 예시 | 설명 |
|---|---|---|
| 총 라운드 수 | `5` | 보통 5 |
| 시작 시드머니(원) | `100000000` | 전 조 동일(1억) |
| **타이머(초)** | `600` | **초 단위!** 600 = 10분 (⚠ 화면 게임설정은 '분', §6 참고) |
| 최종 정산 연도 | `2025` | 대회 종료 시 이 연도 가격으로 최종 평가(매매 없음) |
| R1 연도 | `2020` | 1라운드에서 거래하는 연도 |
| R2 연도 … | `2021` … | 라운드 수만큼 이어서 |

> **라운드 연도(`R1 연도`…)는 「종목」 시트의 `YYYY년 가격` 열과 정확히 일치**해야 한다. 안 맞으면 업로드
> 때 에러로 막힌다.

#### 「종목」 — 한 행 = 종목 하나
헤더: `ID` · `종목명` · `한 줄 소개` · `업종 (선택)` · `상장라운드` · `2020년 가격` · `2021년 가격` …

- **ID** — `S01`, `S02` … 고유 코드. 재무·힌트가 이 ID로 종목을 가리킨다.
- **한 줄 소개** — 학생이 [재무제표] 팝업 맨 위에서 본다. 가격 스토리와 모순 없게(몰락할 회사엔 복선).
  **호재/악재를 대놓고 쓰지 않는다** — 판단은 학생 몫.
- **업종 (선택)** — 비워도 된다. *(지금은 학생 화면에 안 보인다. §6)*
- **상장라운드** — 이 라운드부터 목록에 나타남(신규상장). 보통 `1`, 중간 상장이면 `3` 등.
- **`YYYY년 가격` 열들** — 게임의 뼈대. 칸 채우는 방식 두 가지:
  - **숫자 = 그 해 가격(원).** 예: `29300`
  - **끝에 % = 전년 대비 등락률.** 예: `+80%`(전년보다 80%↑), `-10%`(10%↓). 업로드 때 실제 가격으로
    환산되고, 리포트에 "참고"로 환산 결과가 뜬다.
  - **첫 등장(상장) 연도는 반드시 가격(원).** 첫 칸을 %로 쓰면 기준이 없어 에러.
  - **빈칸 또는 0 = 거래정지·미상장**(매수·매도 차단, 평가액 0). 상장폐지를 이렇게 표현한다.

#### 「재무제표」 — 한 행 = 한 종목의 한 해 (입력 잎 7개만)
헤더: `종목ID` · `연도` · `유동자산(억)` · `비유동자산(억)` · `유동부채(억)` · `비유동부채(억)` · `매출(억)` · `영업비용(억)` · `영업외비용(억)`

- **입력하는 값은 7개뿐, 전부 억원.** 자산합계·부채합계·자본·영업이익·당기순이익·부채비율·ROE는 학생·관리자 화면이 **자동 계산**한다(입력 X).
  - 영업이익 = 매출 − 영업비용 / 당기순이익 = 영업이익 − 영업외비용 / 자본 = (유동+비유동자산) − (유동+비유동부채) / 부채비율 = 부채÷자본×100 / ROE = 당기순이익÷자본×100.
  - **적자를 만들려면** 영업비용을 매출보다 크게(영업손실), 또는 영업외비용을 크게 넣는다. 입력값 자체는 음수로 넣지 않는다.
  - ⚠ 정본 양식엔 오른쪽에 **`※자동` 표기 열**(자산합계·자본·부채비율·ROE 등, 회색)이 있다 — 값을 **보며 채우는 참고용**이니 **직접 건드리지 말 것**(업로드 때 무시된다).
- **미상장·폐지 연도는 행을 아예 뺀다**(그 해 재무는 화면에서 '-'로 나온다).
- 종목ID는 「종목」 시트에 있는 ID여야 한다(오타면 에러).

#### 「시황」 — 한 행 = 한 해
헤더: `연도` · `한 줄 요약` · `기준금리(%)` · `GDP성장률(%)` · `실업률(%)` · `환율(원/$)` · `물가상승률(%)` · `국제유가($)`

- **한 줄 요약**은 학생 [시황] 팝업 맨 위에 크게 보인다. 예: `인플레이션 급등, 금리 인상 시작 — 성장주 조정`.
- **종목 등락과 방향을 맞춘다.** 예: 금리·물가 급등한 해엔 성장주가 꺾이도록 가격을 짜둔다.
- 연도는 라운드 연도 + 최종 정산 연도 전부 채우길 권장.

#### 「힌트」 — 한 행 = 힌트 하나 (**R1 없음, R2부터**)
헤더: `라운드` · `등급(S~D)` · `힌트 문구` · `방향(up/down/flat) (선택)` · `관련 종목ID (선택)`

- **라운드** — 힌트가 **뜨는** 라운드. 그 해→**다음 해** 등락을 예고한다. **R1은 지급이 없으니 작성하지 않는다.**
- **등급** — `S`/`A`/`B`/`C`/`D`. 좋은 등급일수록 구체적·확신, 낮을수록 모호하게.
- **힌트 문구** — 학생에게 보이는 문장(방향은 안 보임).
- **방향 (선택)** — `up`(호재)/`down`(악재)/`flat`(중립). 비우면 중립 취급.
- **관련 종목ID (선택)** — 쉼표로 여럿. 예: `S04,S02`.
- **방향+관련을 채우면 자동 검증**한다(관련 종목의 다음 해 실제 등락과 방향이 맞는지). **비우면 검증을 건너뛴다**
  (리포트에 "참고"로 표시). 시장 전반 힌트는 방향·관련을 비운다.
- **라운드마다 S~D 등급을 고루** 넣길 권장(자동 배분이 매끄럽다 — §3).

### 1-3. 업로드 — [데이터셋] 탭 → "올리기"

**올리기** 줄의 **[📊 엑셀 업로드 (.xlsx)]** → 파일 선택. 곧바로 **엑셀 검사 결과** 창이 뜬다.
*(옆 [📁 JSON 가져오기]는 백업 .json 복원용이다.)*

### 1-4. 검사 리포트 읽는 법 (3레벨)

| 레벨 | 색 | 뜻 | 예 |
|---|---|---|---|
| **에러** | 빨강 | **차단.** 하나라도 있으면 데이터셋을 못 만든다. 고쳐서 다시 올린다 | 필수 시트/열 누락, **종목ID 참조 오류**(재무·힌트가 없는 종목을 가리킴), **라운드 연도↔가격 열 불일치**, 값이 숫자가 아님, **첫 등장 연도에 %**, 등급이 S~D 아님, 힌트 문구 빈칸, 방향이 up/down/flat 아님, ID 중복 |
| **경고** | 노랑 | **허용.** 확인만 하고 진행 가능 | **힌트 방향↔등락 불일치**(호재인데 다음 해 안 오름), **라운드별 등급 커버리지 부족**(R2~에 어떤 등급이 없음 → 자동배분 때 인접 등급 대체), 게임에 없는 연도 가격 열 |
| **참고** | 회색 | **정보.** 그냥 확인용 | **% 등락률 환산 결과**(예: `S02 2021: +80% → 13,140원`), 방향/관련이 없어 검증을 건너뜀, 모르는 열이 무시됨 |

> ⚠ **검사가 저장을 자동으로 막아주지는 않는다** — 경고는 통과시킨다. **힌트 방향 불일치 경고는 꼭 확인**해서,
> 의도한 게 아니면 고친다(정직하게 판단한 학생이 손해 보는 걸 막는 안전장치).

### 1-5. 새 데이터셋으로 생성 + 사용

에러가 0이면 창 아래에 **이름 입력칸**이 열린다. 이름을 정하고 **[새 데이터셋으로 생성]**을 누른다.

- **기존 데이터셋을 덮어쓰지 않는다** — 항상 **새 한 벌**이 만들어져 목록에 추가된다.
- 만든 데이터셋을 **쓰려면**: 목록에서 그 행의 **[편집]**을 누른다(불러오기 = 라이브가 되고 게임이 리셋됨, 조는 유지).
  또는 [진행] 탭 "이번 게임 데이터셋" 드롭다운에서 골라도 된다.
- 불러온 뒤 화면에서 세밀 수정하고 싶으면 §2로.

## 2. 화면으로 만들기 (즉시 반영 · 세밀 편집)

화면 편집은 **바로 라이브에 반영**된다(학생 화면이 즉시 바뀐다). 다 고친 뒤에는 **[데이터셋] 탭에서 저장**해야
한 벌로 남는다(§2-6). 저장 전에 다른 데이터셋으로 [편집] 전환하면 **고친 게 사라진다.**

### 2-1. 게임 설정 — [진행] 탭 → "게임 설정 (시작 전에만)"

[진행] 탭을 아래로 내리면 **게임 설정** 카드가 있다(시작 전 상태에서만 보인다). **[설정 편집]**을 누르면:

- **라운드 수** — 예: `5`
- **라운드별 연도** — R1~R5 각 칸에 연도. 예: `2020 2021 2022 2023 2024`
- **최종 정산 연도** — 마지막 라운드 다음 해. 예: `2025`
- **기본 시드머니** — 조를 만들 때 기본 원금. 예: `100000000`
- **타이머(분)** — 라운드당 거래 시간. 예: `10`. [타이머 시작]이 이 값을 그대로 쓰고 진행바 기준도 이 값(미세 조정은 진행 중 ±1분). ⚠ 단위 주의: 화면은 **분**, 엑셀 양식은 **초**(600=10분).
- **입장 방식** — 코드(강사가 조·코드 배부) / 자율(학생이 닉네임으로 입장). *운영 설정이라 엑셀 양식엔 없다.*

**[설정 저장]**. 여기서 정한 연도가 이후 가격·재무·시황 편집기의 "연도 칸"을 만든다. **연도는 처음에 확정**한다.

### 2-2. 종목·가격 — [종목·가격] 탭

표에 종목·연도별 가격이 보인다(0/빈칸은 **정지** 태그). **[+ 종목 추가]** 또는 종목 행의 **[수정]**으로 편집기를 연다:

- **종목코드** — 예: `S01` (한 번 정하면 못 바꾼다).
- **종목명** — 예: `승주보험`.
- **한 줄 소개** — 학생이 재무제표 팝업 맨 위에서 본다.
- **업종** — 비워도 된다(학생 화면 미표시, §6).
- **상장 라운드** — 이 라운드부터 목록에 노출.
- **연도별 가격** — 각 연도 칸에 원 단위 정수. **비우면 거래정지.** (화면 편집기에서는 **엑셀과 달리 % 입력은 안 되고
  숫자만** 받는다.)

> 대회 시작 후 가격을 고치면 **이미 체결된 거래엔 소급되지 않는다**(앞으로의 평가·체결에만 적용). 제작은 시작 전에.

**설계 요령 — 종목 유형을 의도적으로 섞어라**

| 유형 | 목적 | 가격/재무 패턴 |
|---|---|---|
| 급등주 | 역전의 재미 | 신작 대박 등으로 급등 |
| 안정주 | 대조군 | 매출·이익 꾸준히↑, 부채비율 낮게(90%대), ROE 8~11% |
| 몰락주 | 리스크 교육 | 매출 커도 영업이익 적자, 부채비율 급등, 급등 후 폭락(→0) |
| 상장폐지 | 0원 처리 | 특정 연도부터 가격 0 |
| 신규상장 | 후반 변수 | 상장 라운드를 3 등으로 |

### 2-3. 재무·시황 — [재무·시황] 탭

- **위쪽 「시황 (거시경제) · 연도별」** — 연도마다 6지표(기준금리·GDP성장률·실업률·환율·물가상승률·국제유가) +
  **한 줄 시황**(전용 칸)을 채우고 **[저장]**(그 해만 저장).
- **아래쪽 「재무제표 · 종목별」** — **종목 드롭다운**에서 종목을 고르고, 연도마다 **입력 7개(유동자산·비유동자산·유동부채·비유동부채·매출·영업비용·영업외비용)**를 채워 **[저장]**. 미상장/폐지 연도는 **[비움]**(행 삭제 = 화면에서 '-').
  - 전부 **억원**. 오른쪽에 **자본·순익·부채비율·ROE가 실시간 계산**돼 보이니, 값을 넣으며 바로 확인할 수 있다(자본잠식이면 ⚠ 표시).

> ⚠ 재무는 **종목별로 드롭다운을 오가며** 입력한다(§6).

### 2-4. 힌트 — [힌트] 탭

- **힌트 풀** — 상단 `R1 R2 …` 탭으로 라운드를 고르고, **[+ 힌트 작성]**으로 만든다. 편집기 입력:
  **라운드 · 등급(S/A/B/C/D) · 영향(호재/악재/중립) · 헤드라인 · 관련 종목(칩 클릭, 없으면 전체 시장)**.
- 목록의 각 힌트에는 등급·문구·영향 태그·지급 조 수가 보인다. 방향이 실제 등락과 어긋나면 **⚠ 등락 불일치** 배지가 뜬다.
- **조별 지급** — 왼쪽에서 힌트를 고르고 특정 조에 **수동으로** 더 줄 수 있다(자동 배분과 별개).
- **자동 배분 미리보기** — R2부터 [연도 넘기기] 때 순위대로 어떤 조가 뭘 받을지 표로 확인.

힌트는 가장 실수하기 쉬우니 **§3에서 따로** 설명한다.

### 2-5. 데이터 점검 — [진행] 탭 → "데이터 점검"

**[데이터 점검 실행]**을 누르면 결과가 뜬다(엑셀 리포트와 같은 규칙, 3레벨).

- **오류(빨강)** = 반드시 고친다 (특히 "힌트 태그는 up인데 실제 down" 방향 불일치).
- **경고(노랑)** = 확인 (라운드에 힌트가 하나도 없음 등).
- **참고(회색)** = 의도된 것이면 무시 가능 (거래정지 처리, 시황 지표 없음 등).

> 저장할 때 자동으로 막아주지 않는다. **저장 전에 반드시 눌러** 확인한다.

### 2-6. 데이터셋으로 저장 + 백업 — [데이터셋] 탭

화면 편집은 라이브일 뿐이라, **[데이터셋] 탭에서 저장**해야 한 벌로 보존된다. 편집 후 다른 탭에 갔다 오면
상단에 **● 저장 안 된 변경**(dirty) 배지가 뜬다.

- **[💾 저장]** — 지금 편집 중인 데이터셋에 **덮어쓰기**(확인 모달). 원래 내용은 사라진다.
- **[+ 새 데이터셋으로 저장]** — 이름·설명 입력 후. 따로 남기고 싶을 때(그게 편집 중이 된다).
- **[📁 데이터 다운로드 (.json)]** — 백업 파일. 팀 공유·인수인계용으로 받아둔다.

## 3. 힌트 제작 상세 (엑셀·화면 공통 · 가장 중요)

### 타이밍 — "R라운드 힌트 = 그 해 → 다음 해 예고"
- **R2 힌트**는 R2 연도(예: 2021)에 뜨고 **다음 해(2022)의 등락**을 예고한다. **R1엔 힌트가 없다.**
- 마지막 라운드(R5) 힌트의 다음 해는 **최종 정산 연도**다.
- 그래서 힌트의 방향·관련 종목은 **관련 종목의 그 해→다음 해 실제 가격 방향과 일치**해야 한다.
  안 맞으면 점검이 **오류/경고**로 잡고, 힌트 목록에 **⚠ 등락 불일치** 배지가 뜬다.

### 방향(호재/악재/중립)
- **호재(up)** = 다음 해 오름 / **악재(down)** = 내림 / **중립(flat)** = 시장 전반·방향 없음.
- **학생에겐 방향이 안 보인다.** 문구와 재무·시황으로 학생이 스스로 판단한다. 방향은 **제작자용 검증 태그**일 뿐.

### 등급별 성격 (S가 가장 확실 → D가 가장 모호)

| 등급 | 성격 | 예시 문구 | 방향 / 관련 |
|---|---|---|---|
| **S** | 가장 확실·강력 | "D게임즈 신작, 사전예약 서버가 마비됐다… 업계 '역대급 흥행' 확신" | 호재 / D게임즈 |
| **A** | 강하지만 조건부 | "거품 논란의 모빌리티 업계, 투자금이 마르고 있다는 소문 — F모빌리티 자금난설" | 악재 / F모빌리티 |
| **B** | 방향 뚜렷, 대상 넓음 | "바이오 임상 발표 시즌 도래… 일부 바이오 기업에 큰 장이 설 것" | 호재 / 바이오주 |
| **C** | 애매·해석 필요 | "작년에 SNS에서 유행한 것들, 올해도 유행하리란 법은 없다" | 악재 / 관련주 |
| **D** | 힌트인 듯 아닌 듯 | "시장이 흔들릴 때는 오히려 금융이 웃는다는 옛말이 있다. 늘 맞는 말은 아니지만." | 호재 / 금융주 |

### 배분 방식 (자동 · 라운드로빈)
- **[연도 넘기기]** 때 그 라운드 힌트 풀을 **등급 좋은 순(S→D)**으로 줄 세워, **순위 꼴찌부터 1위 방향으로
  한 장씩 라운드로빈**해 **전부** 나눠준다. → **하위권일수록 좋은 힌트 + 더 많은 개수**(역전 기회).
- **라운드당 힌트 개수는 자유.** 등급별 1개일 필요는 없다(다만 S~D 고루 있으면 배분이 매끄럽다).
- 조 수보다 힌트를 몇 개 더 만들면 하위권이 2장씩 받는다. (예: 7조 × 11힌트 → 꼴찌 2장, 1위 1장)
- [힌트] 탭 **자동 배분 미리보기**에서 조별로 뭘 몇 개 받을지 확인한다.

## 4. 완성 체크리스트 (인쇄용)

새 게임을 다 만든 뒤 확인:

- [ ] 게임 설정: 라운드 수·연도·최종연도·시드·타이머가 의도대로 (**타이머 단위** 엑셀=초 / 화면=분)
- [ ] 라운드 연도 = 종목 가격 열 = 재무/시황 연도가 서로 일치
- [ ] 모든 종목이 **라운드 연도 + 최종 연도** 가격을 채움(또는 의도된 0/빈칸=정지)
- [ ] 상장 라운드 이전 연도만 비어 있고, 엑셀이면 **첫 등장 연도는 가격(원)** (%로 시작 안 함)
- [ ] 모든 종목에 **한 줄 소개**
- [ ] 재무: 등장 연도마다 입력 7개(유동/비유동 자산·부채, 매출·영업비용·영업외비용). 미상장/폐지 연도는 행 없음/[비움]
- [ ] 시황: 모든 연도에 6지표 + 한 줄 요약
- [ ] **힌트 방향 = 실제 등락** (⚠ 배지·오류 없음, 방향 불일치 경고 확인)
- [ ] R2~마지막 라운드에 힌트가 **최소 조 수 이상**, 등급 S~D 고루 / **R1엔 힌트 없음**
- [ ] **[데이터 점검] / 엑셀 검사 리포트에 에러 0**
- [ ] [데이터셋]으로 **저장** + `.json` **백업**

## 5. 자주 하는 실수

- **엑셀 첫 등장 연도를 %로 씀** → 기준 가격이 없어 에러. 상장(첫) 연도는 **가격(원)**으로.
- **라운드 연도와 가격 열이 안 맞음**(게임설정 `R2 연도`=2021인데 종목 시트에 `2021년 가격` 열이 없음) → 에러.
- **엑셀 타이머를 '분'으로 착각** → `10`을 넣으면 10초가 된다. **엑셀은 초**(600=10분). 화면은 분.
- **힌트 방향을 실제 등락과 반대로** → ⚠ 배지·경고. 정직하게 판단한 학생이 손해를 본다.
- **R1에 힌트를 만듦** → R1은 지급이 없어 무의미. R2부터.
- **화면 편집 후 [데이터셋] 저장 안 함** → 다른 데이터셋으로 [편집] 전환하면 사라진다. dirty 배지가 뜨면 저장.
- **엑셀 업로드가 기존 데이터셋을 덮어쓴다고 오해** → 항상 **새 데이터셋**이 생긴다. 쓰려면 목록 [편집].
- **게임 설정에서 연도를 나중에 바꿈** → 이미 입력한 가격·재무·시황이 옛 연도에 남아 화면에서 사라진다.
  **연도는 처음에 확정.**

## 6. 알아두면 좋은 제약 / 발견된 문제

- **[개선 필요] 업종(sector) 미표시** — 종목 편집기·엑셀에 입력칸이 있으나 **학생 화면 어디에도 안 나온다**
  (student 컴포넌트에서 `sector`를 안 씀 — 확인함). 지금은 비워도 무방.
- **[주의] 타이머 단위가 화면(분) ≠ 엑셀(초)** — 같은 값을 두 곳에 그대로 넣으면 안 된다.
- **[주의] 검사는 수동·경고는 통과** — 엑셀 검사도 [데이터 점검]도 경고는 막지 않는다. **반드시 눌러** 확인한다.
- **[주의] 연도 변경 시 데이터 고아** — 위 §5 마지막 항목.
- **[개선 필요] 재무 편집 동선** — [재무·시황] 탭의 종목 드롭다운 방식이라 종목별로 오가야 한다.
- **[개발자 몫] 지표 자체를 바꾸려면** — 재무 입력 7개·시황 6지표의 **종류·이름·단위**를 바꾸는 건 코드
  `src/metrics.js` 한 곳 수정(개발자). 교보재팀은 그 지표의 **값만** 채운다. (지표를 바꾸면 화면·엑셀 양식·
  업로드 파서가 함께 따라간다.)
