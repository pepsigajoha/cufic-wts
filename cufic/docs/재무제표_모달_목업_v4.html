용어 설명 (누르면 접기/펼치기)

유동자산 — 1년 안에 현금으로 바꿀 수 있는 재산이에요 (현금, 팔 물건 등).
비유동자산 — 오래 쓰는 재산이에요 (공장, 기계, 건물 등).
부채 — 갚아야 할 빚이에요. 유동(1년 안에)과 비유동(천천히)으로 나눠요.
자본 — 자산에서 빚을 뺀, 진짜 내 돈이에요. 자산 = 부채 + 자본은 항상 성립해요.
영업비용 — 장사하는 데 든 돈이에요 (재료비, 인건비 등).
영업이익 — 본업으로 남긴 이익 / 당기순이익 — 전부 계산하고 최종적으로 남은 이익이에요.
부채비율 — 내 돈(자본) 대비 빚이 몇 배인지예요. 낮을수록 안정적이에요.
ROE — 내 돈으로 얼마나 잘 벌었는지예요. 높을수록 장사를 잘한 거예요.
